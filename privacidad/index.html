Política de privacidad

Última actualización: 23 de noviembre de 2026

Mente Infinita Publicador es una herramienta interna del canal Mente Infinita. Su única función es publicar los vídeos del propio canal en sus cuentas oficiales de YouTube, TikTok, Instagram y Facebook.

Qué datos usa

  • Los tokens de acceso que el titular de las cuentas concede mediante el inicio de sesión oficial de Google, TikTok y Meta, con los permisos mínimos para subir y programar vídeos y comprobar su estado.
  • Los vídeos, portadas y textos que publica el propio canal.

Qué no hace

  • No recoge datos de espectadores, seguidores ni de ninguna otra persona.
  • No vende, comparte ni cede datos a terceros.
  • No usa los datos para publicidad ni para entrenar modelos.

Almacenamiento y seguridad

Los tokens se guardan cifrados como secrets de GitHub Actions, accesibles solo para el titular, y se usan únicamente para llamar a las API oficiales (YouTube Data API, TikTok Content Posting API, Instagram Graph API y Facebook Graph API). El uso de datos de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El titular puede retirar el permiso en cualquier momento desde su cuenta de Google, los ajustes de aplicaciones de TikTok y la configuración de integraciones de Meta. Al revocarlo, los tokens dejan de funcionar y se borran.

Contacto

Para cualquier consulta, escribe al canal por mensaje directo en Instagram o Facebook.
